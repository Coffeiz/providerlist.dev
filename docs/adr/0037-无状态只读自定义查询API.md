# ADR-0037 · 无状态只读自定义查询 API

> 状态：已接受 · 日期：2026-10-30
> 取代范围：PRD-API-1 中“Builder 仅本地投影、不提供自定义查询 URL”的决定；不取代 ADR 0001 的静态发布与官方写入隔离。

## 背景

API 页 JSON Builder 已可按 Provider、市场、模型类型、供应状态筛选数据，并选择字段。用户希望将选好的配置做成可直接请求的 API URL，持续取得相同投影结果。

整个目录无需放进数据库，但浏览器请求大型完整文件并逐端处理，也不方便直接分享投影结果。与此同时，任意查询表达式、持久化 Builder 配置或上游实时请求会扩大接口与故障边界。

## 决策

增加唯一运行时只读路由 `GET /v1/query.json`。Worker 在请求时只读取同一部署中的 `/assets/datasets/offerings.json`、`providers.json` 和被选 Provider 的详情文件，执行有限筛选和字段投影，返回 `{ "data_version": "…", "data": … }`。

- 只允许 `providers`、`markets`、`types`、`statuses`、`fields` 五个查询参数。列表值为逗号分隔、必须来自已发布数据或字段白名单；不支持任意表达式、字段路径、排序、分页或映射。
- 输出固定为 `{ "data_version": "…", "data": [OfferingProjection, ...] }`，每个数组元素对应一个 Offering；字段枚举与 Builder 一致。仅模型 ID 预设通过只选择 `model_id` 字段生成相同对象数组结构。
- 结果基于当前已发布版本；响应不宣称为标准 Provider、ModelList 或 OfferingList 资源，不加入静态 Manifest，也不新增为此专用的 Schema。
- 允许无凭据跨域 GET；不接受写方法，不存储查询，不访问数据库、官方 API 或其他上游。
- 资源版本不一致时失败关闭。请求 URL 上限 4096 字符，最多 50 个 Provider、5000 条 Offering 和 5 MiB 响应；超出时返回明确 JSON 错误。
- 成功响应采用最多 300 秒共享缓存；标准静态 v1 文件继续由静态资源路径直接提供。
- Builder 的可调用 API URL 与用于恢复 UI 配置的分享 URL 分开显示。

## 备选方案

### 只保留浏览器本地构建

未选：结果可下载，但使用者无法通过稳定 URL 获取更新后的已发布数据。

### 将查询配置保存到服务端

未选：需要写入权限、持久化、生命周期及滥用治理；用户的选择可直接编码在 URL 中，无需保存。

### 通用查询语言或动态 SQL/JSONPath

未选：扩大可执行查询面、复杂度与资源消耗，不符合有限声明式数据规则。

## 后果

- Builder 预览、导出的 JSON 和 API 响应需要保持相同过滤、字段与结构语义。
- Worker 成为静态站点数据上的窄只读投影层；应维持对参数、数据量、响应体积、版本一致性和缓存行为的显式限制。
- 该接口返回当前版本，缓存过期或新版本发布后，同一 URL 可得到新数据。需要固定版本的消费者应下载 Manifest 中的静态资源。
- 新增端点不能改写静态数据、Manifest 或官方接入写入路径。
