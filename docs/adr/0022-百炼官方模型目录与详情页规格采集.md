# 0022：百炼官方模型目录与详情页规格采集

- 状态：已接受
- 日期：2026-10-25
- 决策人：用户

## 背景

百炼模型大全的推荐卡片不是完整型号列表。官方「服务支持 → 模型列表」按文本生成、视觉理解、全模态、图像/视频生成、世界模型、3D、语音、向量与重排序、决策模型等类别提供完整清单，并链接到逐模型详情页。详情页包含输入/输出模态、上下文长度、限流及逐模型能力。此前采集器只读取推荐模型与文本生成目录，导致其他类别型号缺失，规格字段长期为未知。

## 决策

百炼中国区适配器将官方服务支持模型列表索引所链接的全部分类清单中的精确型号并入 CN 模型候选，保留官方分类，并作为当前公开供应目录观察。全部 13 个分类页均为必需来源；目录页缺失、没有分类链接或解析数量异常时采集失败，不能退化成只收文本生成。继续采集结构化按量价格页中的精确型号，按既有 ADR 0021 转换价格与供应观察。

逐模型规格只从以下官方来源中预先审核并写入固定来源白名单的同域 `.md` 页面采集：`https://docs.bailian.console.aliyun.com/llms.txt`，以及「服务支持 → 模型列表」分类页直接链接的详情页。运行时必须验证详情页 URL 与目录中的模型 ID 精确配对；不得根据模型 ID 拼接 URL。模型页面一级标题必须与来源映射中的精确模型 ID 一致；不一致或缺失的页面不产生规格事实。只抽取页面明确列出的模态、上下文/输入/输出长度、限流和能力值。按地域变化的能力仅使用页面中中国大陆地域的表格；没有中国大陆条目时不跨区推断。未披露字段继续保持未知。

Offering 模态契约增加可选 `modalities.output`，与 `modalities.input` 分开保存。模型详情来源和字段断言进入证据链；价格仍由统一价格表转换，不从详情页重复建价。

此例外只适用于阿里云百炼，不改变其他 Provider 禁止采集单模型专属页面的规则；也不允许抓取器根据页面内容任意拼接或跟随 URL。

## 考虑过的方案

- 继续只采集推荐模型卡片或文本生成目录：会遗漏官方完整分类目录及 embedding、语音、图像、视频等型号。
- 手工抄录详情页规格：难以随页面变化更新，也无法在每次采集时核对来源快照。
- 根据模型 ID 自动生成 URL：页面 slug 不总能从模型 ID 推导，容易错配或扩大抓取边界。

## 后果

- 百炼 CN 模型列表覆盖官方服务支持模型列表索引下 13 个分类的完整条目集合，按官方分类转换。
- 可以从精确匹配的详情页补充逐模型上下文、输出上限、输入/输出模态和模型能力。
- 无法精确匹配页面标题、文档不提供字段或仅有其他地域数据时仍显示未知。
- 模态契约变化需同步 TypeScript、JSON Schema 与数据契约文档；候选体量和采集时长会增加。
