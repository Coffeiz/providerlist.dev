# 0021：百炼按量价格行补充当前供应目录

- 状态：已接受
- 日期：2026-10-25
- 决策人：用户

## 背景

百炼模型大全/推荐目录未覆盖按量价格页中的全部型号，导致已经列出明确 Token 价格的模型没有进入 ProviderList 当前供应目录。用户明确要求：中国区和国际站价格页中列出的模型都应计为对应市场的供应中模型。

## 决策

对阿里云百炼这一 Provider，将登记的中国区与国际站官方按量价格页中，结构化 Token 价格表明确列出的精确模型 ID 作为对应市场的供应观察。即使模型 ID 未出现在模型大全/推荐目录，也创建 `active` Offering，并按其结构化价格行转换费率。

该例外不扩展到其他 Provider，不从价格页正文、套餐、缓存说明或无法解析为模型价格行的文字创建 Offering。供应观察不代表某个账号已开通或 API 调用已实测；费率仍保留市场、币种、部署区域和输入长度条件。

## 考虑过的方案

- 仅把模型大全/推荐目录当供应真源：会继续遗漏价格页中有明确型号和按量价格的模型，与用户确定的目录口径不符。
- 对所有 Provider 一概接受价格页型号为当前供应：会混淆历史价格、计划权益和型号提及，也没有用户要求的普遍授权。

## 后果

- 百炼目录模型数会增加，价格页新增的 ID 将纳入统一转换和差异评审。
- 若百炼价格页保留了过期但仍有结构化价格的型号，该规则也会将其纳入当前供应；后续只有出现明确生命周期证据或用户调整口径时才改变状态。
- 其他 Provider 仍按各自批准的当前目录证据决定供应状态。
- `docs/data/data-policy.md` 与 `docs/guides/ingestion_cn.md` 记录此单一 Provider 例外。
