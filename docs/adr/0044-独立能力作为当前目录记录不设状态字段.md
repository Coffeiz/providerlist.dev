# ADR 0044：独立能力作为当前目录记录，不设状态字段

- 状态：已接受；能力归属及市场字段由 ADR 0045 更新
- 日期：2026-11-02
- 取代：[ADR 0041](0041-扁平供应状态与Git生成更新时间.md) 中关于 Service Capability 使用 `supply_status` 和 `availability` 的决定；Service 与 Offering 的状态规则不变。

## 背景

独立能力作为当前目录内容维护。能力级 `supply_status` 与 `availability` 重复标记目录收录状态，且没有在公开能力数据中提供有效信息。原决定允许 Provider 与 Service 两层存放能力，并在能力条目上记录市场。

## 决策

1. 独立能力不包含 `supply_status` 或 `availability`。一条能力出现在目录中，即表示 ProviderList 当前收录该能力。
2. 采集结果不能因单次缺席而自动移除能力；移除仍须在采集差异审阅中确认。
3. 网站不为独立能力显示供应/可用状态徽标；Provider 及 Offering 的供应状态显示规则不变。

## 后果

Provider Schema、TypeScript 类型、IR、采集映射、统计、能力索引、公开 Feed 示例、PRD 与数据文档统一使用新字段。旧状态字段由 `additionalProperties: false` 拒绝；能力层级和市场字段由 ADR 0045 统一。
