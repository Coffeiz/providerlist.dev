# ADR 0033：3D 生成作为标准模型类型

- 状态：已接受
- 日期：2026-10-25
- 决策人：用户
- 关联：ADR 0002（模型类型与 Capability 解耦）、ADR 0032（Model 模态与类型唯一归属）

## 背景

腾讯 TokenHub 当前目录包含开发商发布的三维模型，例如 HY 3D 与 HY-World。Model 注册表已记录其中部分型号为 `3d`，但标准类型词典不认识该值，网站因此把这些已明确分类的型号放进「其他」。

## 决策

1. 将 `3d` 加入标准模型类型，展示为「3D 生成」。
2. `3d` 仅表示模型主类别；输入/输出模态仍记录在 Model 注册表的 `modalities`。
3. 绑骨、动画、格式转换等后处理端点属于 Operation 或独立服务能力，不因为相关资产是 3D 而伪装成模型。
4. 未知模型类型仍保留原值并按开放枚举规则校验，不自动归并到其他已知类型。

## 后果

- 官方明确归类为三维生成的模型会从「其他」进入「3D 生成」类别。
- 标准类型数由十类增至十一类，TypeScript 词典、公开 Schema 与类型文档同步更新。
- Model 的输入输出模态和操作能力继续由各自字段表达，避免把类别当作能力事实。
