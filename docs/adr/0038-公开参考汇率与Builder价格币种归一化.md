# ADR-0038 · 公开参考汇率与 Builder 价格币种归一化

> 状态：已接受 · 日期：2026-10-31
> 取代范围：PRD-API-1 中将参考汇率仅保留在站点资产层、排除于稳定 v1 契约的要求。

## 背景

JSON Builder 面向 Agent 项目提供统一可用的模型价格。原始价格必须继续保留供应商实际币种，但用户需要能选择目标币种；同时消费方需要可追溯的汇率快照，而不能依赖站点私有资源或内置汇率。

## 决策

- 构建存在且通过校验的参考汇率快照时，除站点资产副本外，也发布同版本的 `/v1/fx.json`，复制其公开 Schema 到 `/v1/schema/fx-reference.schema.json`，并将两者纳入 Manifest。没有有效快照时不发布 FX 文件。
- Builder 默认使用 `original`，并只提供该 FX 快照实际覆盖的目标币种。分享 URL 和 `/v1/query.json` 使用相同的 `currency` 值。
- 价格归一使用共享的十进制 FX 转换逻辑。只有某条价格规则中的所有费率均可转换时才整体转换；若缺少所需汇率则原样保留该规则及其币种。
- 含 `pricing` 的投影响应包含 `pricing_currency`，说明请求的目标币种；值为 `original` 时保持来源币种。参考换算不是结算价格，不修改标准 Provider、Offering 或源 RateCard 的原值。

## 后果

- `/v1/fx.json` 是可选公开静态契约，Manifest 和 API 文档必须以实际产物为准。
- Worker、浏览器预览与下载使用同一个共享投影逻辑；汇率与目录数据版本不一致时停止处理。
- 外部使用者可自行读取公开汇率快照并复算；目标币种缺少报价时得到保留原币的规则，不会被伪装为目标币。
