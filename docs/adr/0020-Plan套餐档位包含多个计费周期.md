# ADR 0020：Plan 套餐档位包含多个计费周期

- 状态：已接受
- 日期：2026-10-24
- 补充：[ADR 0019](0019-Provider按市场划分Service并将套餐作为Plan.md)

## 背景

同一市场、同一套餐档位可能同时提供月付与年付，且标准价、促销价和促销条件可以不同。把每个周期存成独立 Plan 会重复套餐倍率和权益，也没有明确表达它们属于同一档位。

## 决策

- `Plan` 表示套餐档位；其 `billing_options[]` 表示可选计费周期。
- 周期、标准价、优惠价、促销说明、截止日期和价格证据都存于各自 `billing_options[]` 项。
- 套餐名称、用量倍率、权益和适用模型等跨周期共享的信息保留在 Plan 上。
- 只有官方资料明确列出的周期才能创建计费选项；不推算未公布的月费或年费。
- 页面仅在当前市场存在多个已知周期时显示周期切换；切换后只展示该周期有选项的套餐。

## 备选方案

- **每个周期一条 Plan**：未采用，因为会复制套餐档位属性，并依赖名称或人工分组来识别同一档位。
- **Plan 顶层继续保存单个周期和价格，再增加分组 ID**：未采用，因为仍需维护重复字段并增加跨 Plan 的引用关系。

## 后果

- 月付和年付可独立保存价格与促销证据，同时共用稳定的套餐 ID、倍率和权益。
- 当前仅公布一种周期的套餐不显示无意义的切换按钮。
- 下游消费者需要从 `billing_options[]` 读取价格；原 Plan 顶层计费字段不再属于公开契约。
