# 隐私政策

> 使用统计功能已实现，部署后开始收集。保留期限和删除方式需在上线前根据 Cloudflare 的实际配置确定。

## 收集的数据

本站通过 Cloudflare Analytics Engine 统计以下事件，用于改进目录和使用体验：

| 事件 | 记录内容 |
|---|---|
| 页面访问 | 页面类型、界面语言、市场 |
| 打开 Provider | Provider ID、来源页面类型 |
| 复制 ID | Provider 或 Model 类型、ID、页面类型 |
| 复制 URL | URL 类别、页面类型 |
| 搜索 | 搜索位置、结果数量 |
| 打开搜索结果 | 结果类型、Provider ID；模型结果还记录 Model ID |

搜索在输入停止 500 毫秒后统计，不记录搜索词。已识别的自动化流量会尽量从统计中排除。复制 URL 只记录类别，不记录 URL 内容。页面类型使用固定分类，不记录完整地址或查询字符串。

## 不收集的数据

统计事件不包含姓名、账号、Cookie、广告标识符、搜索原文、复制的 URL、API 密钥或模型请求内容。本站不使用这些事件识别个人、投放广告或跨站追踪。

## 存储与第三方

统计事件存储在 Cloudflare Analytics Engine。Cloudflare 在提供服务时可能处理网络连接信息，其范围和保留方式取决于 Cloudflare 的政策与实际服务配置。

如果收集内容或用途发生变化，我们会更新本政策。隐私问题可通过项目 GitHub 仓库提交 Issue 联系维护者。
