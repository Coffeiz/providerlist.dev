# Privacy Policy

> Usage analytics has been implemented and will begin collecting data after deployment. The retention period and deletion process must be confirmed against the actual Cloudflare configuration before launch.

## Data we collect

ProviderList uses Cloudflare Analytics Engine to record the following events and improve the directory and site experience:

| Event | Data recorded |
|---|---|
| Page view | Page type, interface language, market |
| Provider opened | Provider ID, source page type |
| ID copied | Provider or Model type, ID, page type |
| URL copied | URL category, page type |
| Search | Search location, number of results |
| Search result opened | Result type, Provider ID; Model ID for model results |

Searches are counted 500 milliseconds after typing stops; search terms are not recorded. Identified automated traffic is excluded where possible. URL copy events record the category, not the copied URL. Page types use fixed categories; full addresses and query strings are not recorded in analytics events.

## Data we do not collect in analytics events

Analytics events do not include names, accounts, cookies, advertising identifiers, search text, copied URLs, API keys, or model request content. We do not use these events to identify individuals, serve ads, or track users across sites.

## Storage and third parties

Analytics events are stored in Cloudflare Analytics Engine. Cloudflare may process network connection information while providing its services. The scope and retention of that information depend on Cloudflare's policies and the actual service configuration.

We will update this policy if the data collected or its uses change. For privacy questions, please open an issue in the project's GitHub repository.
