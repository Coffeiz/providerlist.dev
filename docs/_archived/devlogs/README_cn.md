# devlog

排查过程记录。**不**放产品需求、架构决策或当前规范——
产品需求归档于 `docs/_archived/prds/`，决策记录位于 `docs/adr/`，当前规范位于 `docs/*.md`。

## 写什么

一次排查的完整过程：

1. **现象**——看到了什么，期望是什么。
2. **假设与排除**——试过什么，怎么排除的。
3. **根因**——真正的原因。
4. **修复**——改了什么，为什么这么改。
5. **回归防护**——加了什么测试或检查防止复发。

## 不写什么

- 产品需求与验收标准 → `docs/_archived/prds/`
- 架构决策与取舍 → `docs/adr/`
- 规范与契约 → `docs/*.md`
- 日常 commit 摘要 → Git 历史
