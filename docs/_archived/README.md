# Archived project records

This directory contains historical Product Requirements Documents (PRDs) and investigation logs. These records are retained for traceability; they are not the source of truth for current behavior.

- [`prds/`](prds/README_cn.md): Chinese PRDs and migration reports. Completed PRDs are marked `【已完成】` in their filenames.
- [`devlogs/`](devlogs/README_cn.md): Chinese investigation and implementation records.

Current contracts, policies, and operating guidance are indexed in [`docs/README.md`](../README.md). Chinese archive documents use the `_cn` filename suffix. Supporting CSV and JSON artifacts remain beside the records that reference them.
